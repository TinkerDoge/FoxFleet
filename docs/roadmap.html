        How to use and update this page

        This is one file with no dependencies. Open it in any browser (even from disk) on a phone or desktop.

        • Ticking a box is saved in this browser only (localStorage). It does not change the file.
        • Updating the project: edit the JSON block at the top of roadmap.html (the part marked EDIT ME). Change version and updated, add a timeline entry per release, and move board items between columns by changing their col (Done, In progress, Next, Later). Give a new item a unique id.
        • Items already ticked on a phone keep their tick if the id stays the same. Use the reset button to start from the file again.
        • The JSON block in docs/roadmap.html is the source for this tracker and the published roadmap. The docs build checks the version and provider statuses against the code.
        • For unfinished work, set an area, a detail description, and a doneWhen completion criterion. Mark features implemented separately from their real-world validation.
