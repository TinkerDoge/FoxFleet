features:
  - title: One hub, many agents
    details: Hermes machines, OpenAI-compatible APIs, OpenRouter, Z.ai, OpenCode, Grok and MCP-inbox agents sit side by side. Add or reorder them from a form generated by the hub.
    link: /agents/
  - title: Private by design
    details: Hosts, URLs and API keys are write-only on the hub. Clients only see names, status and capabilities. Remote Markdown images are fetched by the hub, not your browser.
    link: /security/
  - title: No open ports for your agents
    details: The connector on an agent machine dials out to the hub over one WebSocket. No public hostname or port forwarding for the agent.
    link: /concepts/connector
  - title: Real accounts
    details: First-run owner, optional invites, scrypt passwords, rotating sessions with a device list, lockout and sign-out everywhere.
    link: /concepts/accounts
  - title: Rich chat
    details: Streaming replies, Markdown with tables and code copy, reasoning blocks, images, files, voice, slash and hash commands, a fullscreen media viewer.
    link: /apps/chat
  - title: Desktop takeover
    details: Watch an agent's desktop, take control, hand it back. Single-use tickets, a 15-minute cap and a red border while you hold control.
    link: /apps/screen
  - title: Web and Android, same design
    details: A Preact web app (installable PWA) and a Kotlin/Compose app share one set of design tokens, light and dark.
    link: /apps/chat
  - title: Small and boring to run
    details: The hub is one Node process with no runtime dependencies. Docker, systemd, a Cloudflare Tunnel or Caddy/nginx all work.
    link: /hosting/
