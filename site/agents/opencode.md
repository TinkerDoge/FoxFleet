# OpenCode

OpenCode Zen models with your OpenCode API key. Preset base URL: `https://opencode.ai/zen/v1`.

Fields: **Model** (required; the id as OpenCode lists it), **API key** (required), and under *advanced* an optional **Base URL** if you run your own OpenAI-compatible OpenCode endpoint. **Capabilities:** chat, images.

Status in the [roadmap](/project/roadmap): *Beta*. If your OpenCode setup is a local server rather than Zen, the [OpenAI-compatible](./openai) kind is the better fit.
