# OpenRouter

Hundreds of models behind one key. Foxfleet uses the preset `https://openrouter.ai/api/v1` (kept on the hub).

1. Create an API key at openrouter.ai.
2. **Add → OpenRouter**: **Model** (default `openai/gpt-4o-mini`; any id from <https://openrouter.ai/models>) and **API key** (required).
3. **Test connection** → *Models listed*. Save.

**Capabilities:** chat, images (if the chosen model accepts them). Billing is between you and OpenRouter; Foxfleet adds none.
