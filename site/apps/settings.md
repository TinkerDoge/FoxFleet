# Settings and devices

## Web

| Setting | Options |
| --- | --- |
| Theme | Light, dark (follows the system by default) |
| Accent | Ember (default, the fox orange), Ocean, Moss, Iris, Graphite |
| Text size | Small, medium, large |
| Motion | Follow system / reduce motion |

Stored in the browser only. Sidebar → **Account** (*Devices and security*) lists your signed-in devices, lets you **revoke** one, **sign out everywhere**, and **change your password** (needs the current one; every *other* device is signed out).

## Android (Settings)

**Manage agents**, **Reduce motion**, **Haptics**, **Notifications**, **Hubs** (add, switch, remove hubs), **Admin** (owners), **Devices & security**, **Sign out**.

Both apps follow the same design tokens (`design/tokens.json`), so colours, radii and spacing match.
