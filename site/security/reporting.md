# Reporting a vulnerability

Please report privately: open a **GitHub security advisory** on the repository (*Security → Report a vulnerability*), or email the maintainer address on the repository profile. Do not open public issues for security problems.

We aim to acknowledge reports within a few days. This is a small open-source project: there is no bug bounty, but credit in the release notes is gladly given.

Useful details: version or commit, how you run the hub (Docker, systemd, tunnel), steps to reproduce, and impact. Never include real keys or tokens in a report.

See also the repository's [`SECURITY.md`](https://github.com/TinkerDoge/FoxFleet/blob/main/SECURITY.md).
