In each cell put the same cute front-facing chibi pixel-art golden Shiba with the exact face, ears, muzzle, eye shapes, fur palette of the reference, plus a small simple seated body and tiny paws. Retro game sprite art with hard stair-step pixel edges, no smoothing, no gradients, no 3D. Each character must have identical scale, bounding box, head center and paw baseline across cells, with at least 12 percent transparent safe padding on every side. Tile order left-to-right then top-to-bottom: 0 idle sitting with both eyes open; 1 same pose with eyelids halfway closed; 2 same pose with both eyes fully closed in a blink; 3 same character sitting with a small bold amber download arrow between the front paws, eyes open; 4 same character with cheerful eyes and a small cream checkmark between the front paws; 5 same character with ears slightly lowered and a worried face, no extra symbols. Match reference warm amber #F4C56B, cream #FFF1CB, brown #835200, charcoal #241D13. Real transparent background everywhere outside sprites. No floor, shadows, scenery, text, letters, watermarks, coins, clothes, or UI mockups. Keep every sprite entirely inside its own cell. Final sprite sheet is meant to be sliced by exact mathematical grid coordinates.
